# RushPoint reels: צנרת עריכה

תבנית מלאה לשלושה סרטונים של היום (ריל המדרגות, ריל ה AI, סבתא) ושלד לריל החידות. כל
סרטון מתרנדר כבר עכשיו עם placeholders צבעוניים, כך שהקצב נראה לפני שיש חומר. כשמגיע
קליפ, שמים אותו בתיקייה בשם שה timeline מצפה לו ומרנדרים שוב.

## הרצה אצלך (Windows, PowerShell)

```powershell
cd C:\Users\ahiya\Desktop\RushPoint\docs\marketing\tools\reels-edit
pip install pillow numpy python-bidi fonttools
python setup_workspace.py          # יוצר RushPoint-reels-work + RushPoint-reels-out על ה Desktop של המשתמש הנוכחי (%USERPROFILE%)
python test_captions.py            # בודק שהעברית בכתוביות יוצאת בסדר הנכון
python variants.py reel2-stairs    # A/B/C + קאבר + QA, איכות תצוגה
python variants.py reel2-stairs --final   # מאסטר; מעביר ל out רק מה שעבר QA מלא
```

אין צורך להתקין פונטים: הקבצים ב `fonts/` מוטמעים גם ב HTML וגם ב libass.

## מבנה

```
RushPoint-reels-work\<reel>\
  timeline.json   ← שוט אחר שוט: start/end, clip, in, speed, effect, blur, captions, sfx, openings A/B/C
  clips\          ← 2A_take1.mp4, 3A_take1.mp4 … (שם הקובץ = מה שכתוב ב timeline)
  voice\          ← reel2_vo.wav וכו'
  proofs\         ← P1.png … P10.png (ריל 3)
  graphics\       ← נוצר אוטומטית (קבלה, הוכחות, קולאז', פואנטה, כותרת, חידות)
  sfx\            ← אפקטים מסונתזים (land, ding, whoosh, pop, hit, riser, tick). קובץ משלך באותו שם מחליף
  build\          ← סגמנטים, subs.ass, <reel>_A.mp4, קאברים, דוחות QA
RushPoint-reels-out\<reel>\   ← רק מה שעבר `--final`
```

| קובץ | מה הוא עושה |
|---|---|
| `config.json` | הגדרה אחת לכולם: רזולוציה, אזור בטוח, צבעים, פונטים, **שער הדולר** |
| `build.py` | מרכיב סרטון אחד מה timeline. קליפ חסר = placeholder עם שם השוט, הקובץ והאורך |
| `variants.py` | מרנדר A/B/C + קאבר לכל אחת + QA, ומעביר ל out |
| `qa.py` | אורך 25 עד 30, 1080x1920, 30fps, H.264+AAC, שוט מעל 3 שניות, שוט סטטי, אזור בטוח (כתוביות + פיקסלים של גרפיקה), מקפים, לופ (פריים ראשון מול אחרון + שורת הסוף ושורת הפתיחה כמשפט אחד), TODO |
| `lib/captions.py` | כתוביות מילה אחר מילה, המילה הפעילה ב #FFB300 |
| `lib/graphics.py` | כל הגרפיקה כ HTML דרך Edge headless |

## איך מכניסים חומר

1. קליפים: `clips\2A_take1.mp4` וכו'. 3 טייקים? שים את שלושתם (`_take1/2/3`) וכוון את
   `clip` ב timeline לטוב. גרסאות הפתיחה B ו C כבר מצביעות על take2/take3.
2. ריל המדרגות: עדכן `receipt.landings` לזמני הנחיתה האמיתיים ב 2A, ו `in` של כל שוט.
   כל נחיתה = צליל נחיתה + "דינג" + שורה חדשה בקבלה (מודגשת בענבר). שורה 11 נכנסת רק
   כש `approved: true`. עד אז הקפיצה קורית והקבלה לא גדלה.
3. כתוביות עם תזמון מדויק: במקום `text` אפשר `words: [["מילה", 1.2, 1.5], …]` (למשל
   מ faster-whisper עם `ivrit-ai/whisper-large-v3-turbo-ct2`, ראה `../../playbooks/video-editing-setup.md`).
4. טשטוש: `"blur": [{"x":..,"y":..,"w":..,"h":..,"start":0,"end":1.2}]` על השוט (זמנים בתוך השוט).
5. כל מה שעדיין TODO מופיע בכתום עם מסגרת מקווקוות, ו `qa.py --final` נכשל עליו.

## הערות טכניות שנמדדו כאן

- **libass לא מריץ bidi דרך תגי צבע.** כל `{\c}` פותח ריצה חדשה והריצות מסודרות משמאל
  לימין, אז שורה עם מילה צבועה יצאה עם המילים בסדר אנגלי ו "הבאה:" כ ":הבאה". עטיפת
  RLE לא שורדת את זה. לכן המנוע מסדר את המילים בעצמו (python-bidi) ונועל כל ריצה ב LRO.
  `test_captions.py` משווה לרינדור ייחוס ונכשל אם זה חוזר.
- **overlay של PNG בלולאה לכל אורך הסרטון** פענח 15 תמונות 1080x1920 בכל פריים: 3:15
  לריל אחד. תמונה בודדת עם `eof_action=repeat`: 0:41. המחיר: אין fade in לגרפיקות, הן
  נכנסות על הפריים (על נחיתה זה בדיוק הביט).
- הסגמנטים מחושבים בפריימים שלמים ונחתכים ל `-frames:v` מדויק (gotcha #5 ו #7).
