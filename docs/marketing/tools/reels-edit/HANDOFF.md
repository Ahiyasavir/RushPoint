## 4. מה כבר בנוי

הכל ב `docs/marketing/tools/reels-edit/`. הפירוט המלא ב README.md שבאותה תיקייה.

| קובץ | מה הוא עושה |
|---|---|
| `setup_workspace.py` | יוצר את `%USERPROFILE%\Desktop\RushPoint-reels-work\<reel>\{clips,voice,proofs,graphics,build,sfx}` ואת `RushPoint-reels-out`. מעתיק תבניות timeline (לא דורס) ומסנתז אפקטי סאונד |
| `reels/<reel>/timeline.json` | תבניות לארבעת הסרטונים. ההעתק שעורכים הוא זה שב RushPoint-reels-work |
| `build.py <reel> [--opening B] [--final]` | מרכיב סרטון. קליפ חסר הופך ל placeholder צבעוני עם שם השוט, הקובץ והאורך |
| `variants.py <reel or all> [--final]` | פתיחות A/B/C, קאבר לכל אחת, QA. עם `--final` מעביר ל out רק את מה שעבר |
| `qa.py` | בודק אורך, פורמט, שוט מעל 3 שניות, שוט סטטי, אזור בטוח, מקפים, לופ ו TODO |
| `lib/captions.py` + `test_captions.py` | מנוע הכתוביות העבריות ובדיקה שלו |
| `lib/graphics.py` | קבלה, הוכחות, קולאז', פואנטה, כותרת לסבתא, חידות וקאברים, ב HTML דרך Edge headless |
| `config.json` | הגדרה אחת לכולם, כולל `money.usd_ils_rate` (TODO, לעדכן ביום העריכה) |
| `fonts/` | Rubik, Assistant, JetBrains Mono, Space Grotesk ו Inter כ TTF סטטיים, מוטמעים |

**מצב:** כל 10 הגרסאות (3 לכל אחד משלושת סרטוני היום, ואחת לחידות) מתרנדרות עם
placeholders ועוברות QA. ה TODO מסומנים כאזהרה ובתוך הסרטון מופיעים בכתום. CI של הריפו
ירוק.

**ממצאים שנמדדו (לא לשבור):**
- **libass לא מריץ bidi דרך תגי צבע.** כל מילה שצובעים בענבר פותחת ריצה חדשה, והמילים
  יצאו בסדר אנגלי. המנוע מסדר את המילים בעצמו עם python-bidi ונועל כל ריצה ב LRO.
  `test_captions.py` נכשל אם זה חוזר.
- **שכבות PNG בלולאה לכל אורך הסרטון** הפכו רינדור של ריל אחד ל 3:15. תמונה בודדת עם
  `eof_action=repeat` מביאה אותו ל 0:41. המחיר: הגרפיקות נכנסות בחיתוך, בלי fade.
- `docs/marketing` נעולה ע"י `scripts/test-marketing-structure.ts`, ולכן הכלי יושב תחת `tools/`.

## 7. כלים על המחשב (מהבריף)

- FFmpeg (WinGet, Gyan.FFmpeg). חייב את הגרסה המלאה עם libass, fribidi ו harfbuzz.
- Python 3.11 עם Pillow ו numpy. אין cv2, torch או ImageMagick. צריך גם להתקין python-bidi
  ו fonttools.
- Node ו bun.
- Edge headless: `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`. הקוד קורא
  לו מ Python עם רשימת ארגומנטים, לא דרך Bash, כי לפי הבריף Bash נכשל שם בשקט עם נתיבים.
- מחבר Canva, אם הוא מקצר משהו בקאברים.
- להגדיר `PYTHONUTF8=1` בכל עבודה עם שמות קבצים בעברית. התיקייה "סרטונים 1.10.26" היא
  בדיוק המקרה הזה.
