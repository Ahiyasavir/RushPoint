# מקורות העריכה של ריל 01

הסקריפטים שבנו את הסרטון. הם כאן כדי שאפשר יהיה **לשנות אותו בלי לבנות הכל
מחדש**, למשל לעדכן את הלוח כשנרשמת קבוצה נוספת.

| קובץ | מה הוא עושה |
|---|---|
| `music_gen2.py` | מסנתז את הפסקול. מי מינור עם בס פדל, 149 BPM, 19 תיבות שנסגרות בדיוק על 30.667 שניות. **לא** הלופ Am-F-C-G של הסרטון הקודם. |
| `board_anim.py` | מרנדר את לוח עשרת המקומות. **`TEAMS` בראש הקובץ הוא מה שמעדכנים כשנרשמת קבוצה.** |
| `footage.py` | חותך את קטעי הצילום האמיתיים מהמקור ומתאים אותם ל-1080x1920. |
| `insert3.py` | מרכיב את ההוספות על הראיון עם מעברים של שישה פריימים. מסמן אילו הוספות הן גרפיקה. |
| `burn.py`, `caprender.py`, `caps2.py` | צורבים את הכתוביות, ומפנים להן נתיב כשגרפיקה על המסך. |
| `audio3.py`, `mix.py`, `finalmix.py` | בונים את פס הקול, מווסתים את המוזיקה 10dB מתחת לקול, ומודדים כל רמה. |
| `verify_sync.py` | מוודא סנכרון שפתיים בקורלציה, לכל הקובץ ולכל רבע בנפרד. |
| `*.json` | תוכנית החיתוכים, זמני המילים לכתוביות, וחלונות הגרפיקה. |

## סדר ההרצה
```
music_gen2.py  →  mix.py  →  finalmix.py          (פס הקול)
footage.py     →  insert3.py  →  burn.py          (התמונה)
ffmpeg מאחד את burned.mp4 עם mixed.wav            (המסירה)
verify_sync.py                                     (הבדיקה)
```

**מה שלא כאן:** קבצי הביניים הכבדים וההקלטות הגולמיות. אם צריך לבנות מאפס,
המקורות הם ההקלטה מהמיקרופון והצילום מהטלפון, ו-[../../../../footage/README.md](../../../../footage/README.md)
אומר איפה יושבים הצילומים מהעמדה ומהמשחק.
