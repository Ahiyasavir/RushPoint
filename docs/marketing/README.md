# שיווק

כל חומרי השיווק של RushPoint. **לפני שמוסיפים משהו לכאן, קוראים את החוקים למטה.**
התיקייה הזאת התבלגנה פעם אחת כי לכל קובץ היה שם בשיטה אחרת; החוקים קיימים כדי
שזה לא יקרה שוב.

| תיקייה | מה יש בה |
|---|---|
| [videos/](videos) | כל סרטון, אחד אחד, בתיקייה משלו. מפורסמים וטיוטות בנפרד. |
| [footage/](footage) | חומר גלם שמשרת יותר מסרטון אחד. |
| [graphics/](graphics) | קרוסלות, פוסטרים, קודי QR. |
| [music/](music) | פסקולים ודוגמיות. |
| [playbooks/](playbooks) | איך עובדים. המחקר וההחלטות, לא התוצרים. |
| [tools/](tools) | קוד שמייצר חומרים, כרגע פרויקט ה-Remotion. |

## החוקים

### 1. לכל סרטון תיקייה משלו
```
videos/<מצב>/<NN>-<slug>/
```
`<מצב>` הוא `published` או `drafts`. אין מצב שלישי.
`<NN>` שתי ספרות, לפי סדר ההוספה למבנה הזה, **לא לפי כרונולוגיה**.
מספר לא ממוחזר ולא ממוספר מחדש לעולם, גם אם סרטון נמחק.
`<slug>` באנגלית, מילה עד שלוש, מחוברות במקף. מתאר **מה הסרטון**, לא למי הוא מיועד.

### 2. לכל קובץ אותו שם בדיוק
```
<NN>-<slug>-v<N>.mp4          המאסטר, 1080x1920
<NN>-<slug>-v<N>-small.mp4    עותק לשיתוף, מתחת ל-15MB
```
**`v<N>` תמיד שם**, גם כשיש רק גרסה אחת. `01-missions-v1.mp4`, לא `01-missions.mp4`.
זה מה שמבטל את השאלה "איזה מהם החדש": **הגרסה עם המספר הגבוה היא הנוכחית.**
לכל גרסה יש `-small` משלה. וריאנט נוסף מקבל סיומת אחרי הגרסה
(`-music-only`, `-mail`), אף פעם לפניה.

### 3. לכל תיקיית סרטון יש README עם אותן חמש כותרות
```
## סטטוס        טיוטה או פורסם, ואם פורסם אז מתי ואיפה
## התסריט
## למה זה בנוי ככה
## מה נמדד
## פתוח
```
מותר להוסיף כותרות, אסור להשמיט מהחמש.

### 4. חומר גלם
מקורות של סרטון אחד יושבים ב-`source/` בתוך התיקייה שלו. חומר שמשרת כמה סרטונים
עובר ל-`footage/`. הכלל הפשוט: אם סרטון שני ירצה את זה, זה לא שייך ל-`source/`.

### 5. לפרסם זה להזיז, לא לשנות שם
```
git mv videos/drafts/01-missions videos/published/01-missions
```
ואז לעדכן את שורת הסטטוס ב-README שלו. **שום קובץ לא משנה שם.** ככה קישור שנתת
למישהו לא נשבר, וההיסטוריה נשארת קריאה.

### 6. קבצי mp4 לא נכנסים ל-git
`.gitignore` כאן חוסם `*.mp4` בכוונה, כי git שומר כל גרסה של קובץ לנצח וסרטון
של 30MB שנדרס חמש פעמים משאיר 150MB בהיסטוריה. המאסטרים חיים על הדיסק בלבד.
**זה אומר שאין להם גיבוי.** סרטון שפורסם ואתה רוצה לשמור לתמיד, העלה אותו
ל-`apps/marketing/public/uploads/` (שם כן מקובעים, יש שם תקציב ושומר).

## איפה הדברים שלא כאן

- **הסרטונים שבאמת רצים על האתר** יושבים ב-`apps/marketing/public/uploads/`, לא כאן.
  התיקייה הזאת היא סדנה, זאת היא הפרסום.
- **חומר הגלם מהטלפון** לא בריפו בכלל. ראו [footage/README.md](footage/README.md).
- **כתיבת תסריטים** עוברת דרך הסקיל `video-script`, שמריץ בדיקת סגנון על הטקסט.
