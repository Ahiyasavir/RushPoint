# Slot Unlock Sound Effects

Drop three short MP3 files here (< 2 seconds each, energetic chime/whoosh):

| Filename | Plays when |
|---|---|
| `unlock_green.mp3` | A green open-field slot completes |
| `unlock_orange.mp3` | The orange Tene slot completes |
| `unlock_gold.mp3` | A gold basket slot completes |

If any file is missing the app silently skips the sound — it will never crash.

**Recommended sources:** Freesound.org, Zapsplat, or record custom field sounds.
